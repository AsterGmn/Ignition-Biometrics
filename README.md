# Ignition Biometrics

Ignition Biometrics is a real-time voice anti-spoofing engine developed by V8 Coders for the Altur Hackathon.

Traditional biometric systems are becoming vulnerable to modern voice cloning technology. We built this project to act as a proactive shield, detecting synthetic voices and deepfakes before they can do damage. It is adversarially trained to neutralize tomorrow's synthetic voices, not just yesterday's.

## Key Features

* **Dynamic Chunking:** Processes audio streams in real-time fragments, achieving ultra-low latency without waiting for the full file upload.
* **TitaNet Embeddings:** Uses state-of-the-art context-aware models to extract highly precise vocal footprints.
* **Adversarial Training (F5-TTS):** We actively trained the model against hyper-realistic synthetic voices generated by F5-TTS, making it highly robust against next-gen deepfakes.
* **High-Performance API:** Built on top of FastAPI, offering a stateless and asynchronous backend.

## Architecture \& Tech Stack

* Backend: FastAPI
* Voice Feature Extraction: TitaNet
* Adversarial Generation: F5-TTS
* Server: Uvicorn

## Getting Started

### Prerequisites

* Python 3.9+
* pip

### Installation

1. Clone the repository:

```bash
   git clone https://github.com/your-username/ignition-biometrics.git
   cd ignition-biometrics
   ```

2. Create and activate a virtual environment:

```bash
   # On macOS/Linux
   python -m venv venv
   source venv/bin/activate

   # On Windows
   python -m venv venv
   venv\\Scripts\\activate
   ```

3. Install dependencies:

```bash
   pip install -r requirements.txt
   ```

### Running the Server

Start the FastAPI server using Uvicorn:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at `http://localhost:8000`. You can access the interactive Swagger documentation at `http://localhost:8000/docs`.

## API Reference

### POST /api/v1/verify-audio

Analyzes an incoming audio chunk to determine if it is a bona fide (human) voice or a spoofed (synthetic/deepfake) voice.

**Request:**

* Content-Type: `multipart/form-data`
* Body: `audio\_file` (bytes)

**Response Example:**

```json
{
  "status": "success",
  "analysis": {
    "is\_human": false,
    "confidence\_score": 0.98,
    "classification": "synthetic\_deepfake",
    "latency\_ms": 42
  }
}
```
